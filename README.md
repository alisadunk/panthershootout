# AYSO Panther Shootout

Main information page for the annual AYSO Panther Shootout soccer tournament, hosted by AYSO Region 42.

The tournament takes place over Thanksgiving weekend and welcomes competitive 10U, 12U, and 14U boys' and girls' teams. The page provides tournament information, registration resources, coach and referee guidance, volunteer information, team status, maps, forms, and tournament highlights.

## Local Preview

This is a standalone HTML page with no build step or dependencies. Open `panther_shootout_main.html` directly in a browser, or run:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000/panther_shootout_main.html>.
